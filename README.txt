# GATE DA 2024–2026 PYQ Analyzer

Open `index.html` in a modern browser.

Features:
- Subject-wise navigation
- Unit-wise consolidated questions
- Search
- Year filter
- Individual subject PDF download
- High-priority topics PDF
- Print / Save as PDF fallback

The PDF export uses jsPDF + jsPDF-AutoTable from jsDelivr. An internet connection is required for the one-click PDF export libraries. Browser Print -> Save as PDF works as a fallback.
